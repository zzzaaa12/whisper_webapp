V2 沿用現有 /api/* 路徑。以下範例可直接修改主機位址、網址與通行碼後使用。

快速開始驗證常用端點程式範例Vimeo

快速開始

主要流程是送出網址取得 task_id，再定期查詢任務，直到狀態變成 completed 或 failed。

  1. 1
    建立任務POST /api/process
  2. 2
    保存 task_idstatus: processing
  3. 3
    查詢狀態GET /api/queue/task/<task_id>

驗證方式

如果伺服器啟用了通行碼，請在 JSON 或 multipart form 中傳入 access_code。已經透過瀏覽器完成全站驗證的請求可以沿用 session。

安全提醒

不要把正式通行碼提交到 Git、公開 Apps Script 或前端原始碼。範例中的 YOUR_ACCESS_CODE 必須改由環境變數或 Script Properties 讀取。

常用端點

POST/api/process

加入網址處理任務。JSON 必填 youtube_url 或 audio_url。

POST/api/process2

等待背景任務完成後直接回傳摘要；長時間請求可能受到網路逾時限制。

GET/api/queue/task/<task_id>

取得單一任務的狀態、進度與結果。

GET/api/queue/status

取得等待中與處理中的數量。

POST/api/upload_media

上傳本機影音。使用 multipart 欄位 media_file，最大 2 GB。

GET/api/health

檢查服務是否可連線。

Python

需要安裝 requests：pip install requests

python
import os
import time
import requests

BASE_URL = "http://127.0.0.1:5000"
ACCESS_CODE = os.environ.get("WHISPER_ACCESS_CODE", "")

response = requests.post(
    f"{BASE_URL}/api/process",
    json={
        "youtube_url": "https://www.youtube.com/watch?v=VIDEO_ID",
        "access_code": ACCESS_CODE,
    },
    timeout=30,
)
response.raise_for_status()
payload = response.json()

if payload.get("status") == "completed":
    print(payload["summary"])
    raise SystemExit

task_id = payload["task_id"]
while True:
    task_response = requests.get(
        f"{BASE_URL}/api/queue/task/{task_id}", timeout=30
    )
    task_response.raise_for_status()
    task = task_response.json()["task"]
    print(task["status"], task.get("progress", 0))
    if task["status"] in {"completed", "failed", "cancelled"}:
        print(task.get("result") or task.get("error_message"))
        break
    time.sleep(2)

Google Apps Script

先在「專案設定 → 指令碼屬性」建立 WHISPER_ACCESS_CODE，避免把通行碼寫在程式中。

apps script
function createWhisperTask() {
  const baseUrl = 'https://YOUR_SERVER';
  const accessCode = PropertiesService.getScriptProperties()
    .getProperty('WHISPER_ACCESS_CODE') || '';

  const response = UrlFetchApp.fetch(baseUrl + '/api/process', {
    method: 'post',
    contentType: 'application/json',
    payload: JSON.stringify({
      youtube_url: 'https://www.youtube.com/watch?v=VIDEO_ID',
      access_code: accessCode
    }),
    muteHttpExceptions: true
  });

  const result = JSON.parse(response.getContentText());
  if (response.getResponseCode() >= 400) {
    throw new Error(result.message || 'API request failed');
  }
  Logger.log(result);
  return result.task_id || null;
}

function getWhisperTask(taskId) {
  const response = UrlFetchApp.fetch(
    'https://YOUR_SERVER/api/queue/task/' + encodeURIComponent(taskId)
  );
  return JSON.parse(response.getContentText()).task;
}

curl

建立網址任務
curl -X POST "http://127.0.0.1:5000/api/process" \
  -H "Content-Type: application/json" \
  -d '{"youtube_url":"https://www.youtube.com/watch?v=VIDEO_ID","access_code":"YOUR_ACCESS_CODE"}'
查詢任務
curl "http://127.0.0.1:5000/api/queue/task/TASK_ID"
上傳影音
curl -X POST "http://127.0.0.1:5000/api/upload_media" \
  -F "media_file=@C:/media/example.mp4" \
  -F "access_code=YOUR_ACCESS_CODE"

Vimeo 密碼影片

可以把密碼接在 Vimeo 網址後方，使用一個空格分隔：

簡寫格式
https://vimeo.com/123456789 abc123

API 也支援把密碼獨立放在 video_password。任務查詢與 log 不會回傳原始密碼。

推薦的 API 格式
{
  "youtube_url": "https://vimeo.com/123456789",
  "video_password": "abc123",
  "access_code": "YOUR_ACCESS_CODE"
}
